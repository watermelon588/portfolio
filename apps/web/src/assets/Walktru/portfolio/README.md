# Portfolio delivery media

Six WebP derivatives of the supplied campaign posters in `../design/doodle-posters/posters/`, resized within 1800×2000 at quality 88. No artwork or screen content was generated or replaced. The case imports genuine dashboard/report captures and recording-derived stills directly; their source provenance is in `../README.md` and the launch film documentation.

Laptop mockups are deliberately excluded from this folder and all case body/normal previews. `data/projectEntries/walkthru.ts` references the supplied Walkthru laptop solely through `nextCaseImage` for the footer leading into Walkthru.
