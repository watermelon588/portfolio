# Complete TripVerse design collection

Open START-HERE.html to browse both collections.

- posters/: all files from the original ten-poster campaign pack. Final PNGs and JPEGs are in posters/posters/; editable compositions are in posters/source/.
- mockups/: all files from the ten application mockup pack. Final PNGs are in mockups/png/, JPEGs in mockups/jpg/, and editable compositions in mockups/source/.
- Both collections include their generated artwork, exact brand fonts and licenses, preview galleries, source references, prompts, verification records, rendering scripts, and complete ZIP packs.

Every copied file was verified against its original SHA-256 hash. The original working packs and the separate ten-PNG folders were preserved.

The self-contained editable HTML compositions work independently. Rendering scripts retain their original repository/source paths and should be run from the original output folders as described in each collection's notes.
