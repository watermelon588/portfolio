# TripVerse application mockups

## Product and brand contract

Use actual app screenshots from `frontend/public/guide/` and `frontend/public/home/`. TripVerse is an AI travel planner: travelers chat with a guide, choose a complete itinerary or build day by day, and see the same journey in Plan, Sketch, Map and 3D. Chat changes save to the studio, budget records can be edited, and exports take the trip elsewhere.

Use the original persistent SVG arc mark from `frontend/media/icons/Vector.svg`, Instrument Serif headlines with italic second clauses, Geist body text, Geist Mono metadata, warm bone/ink, hairlines and generous spacing. The app screenshots remain intact. Experimental color and physical mockup settings surround the product.

## Execution and verification

1. Inspect screenshot content and varied source images; match captions to the visible feature.
2. Generate ten distinct art backdrops with the built-in image_gen tool. No generated UI or logo.
3. Composite exact screenshot pixels into locally rendered hardware/browser frames. Add exact fonts and original logo separately.
4. Export each mockup as a high-resolution PNG into `frontend/media/mmm/tripverse-mockups/`, with JPEGs, editable compositions, preview gallery, provenance and prompts in the working pack.
5. Visually inspect every output; verify dimensions, screenshot usage, loaded fonts, canvas bounds, and gallery responsiveness.
