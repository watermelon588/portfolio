# SkyGuide AI — Visual Storytelling & Image Direction
## Detailed Work Section Modification Brief

## 1. Core Objective

Transform the current SkyGuide AI Detailed Work section from a **technical documentation sequence** into a **visual product story**.

The page should make the visitor feel:

```text
LOOK UP
   ↓
BECOME CURIOUS
   ↓
FEEL THE SCALE OF THE SKY
   ↓
REALIZE THE PROBLEM
   ↓
SEE THE PRODUCT
   ↓
UNDERSTAND THE MAGIC
   ↓
SEE THE ENGINEERING
   ↓
FEEL THE HUMAN RESULT
```

Technical credibility must remain.

The presentation should become:

> **visual first + emotional second + technical third**

Use the supplied astronomy imagery as storytelling material, not as decorative filler.

---

# 2. Overall Visual Direction

The image language should communicate:

```text
wonder
curiosity
scale
solitude
discovery
human connection
technology
movement
```

Avoid making the page feel like:

```text

+

+

```

Instead, make it feel closer to:

```text
visual essay
+
product case study
+
engineering story
```

The visitor should feel like they are moving through a night of discovery.

---

# 3. Reference Composition Principle

The reference pages supplied with this brief repeatedly use:

- extremely large visual moments
- short emotional statements
- minimal explanatory copy
- strong typography
- asymmetrical image positioning
- full-bleed imagery
- overlapping compositions
- phone/device compositions
- image sequences
- human figures looking upward
- large areas of negative space
- simple technical captions
- visual transitions between sections

Recreate the **composition language**, not the exact designs.

Do not copy the reference text or branding.

# 23. Image Interaction Strategy

The image treatment should feel alive.

Use the existing portfolio interactions whenever possible.

Desired behaviors:

### Large still image

```text
scroll into viewport
→ subtle reveal
→ slight scale
→ settle
```

### Product screenshot

```text
scroll
→ image enters
→ subtle parallax
```

### Device composition

```text
scroll
→ phone / desktop shift slightly
→ composition settles
```

### Atmospheric image

```text
slow parallax
+
text remains stable
```

Keep movement slow and cinematic.

Do not make images bounce.

# 25. Negative Space

Negative space is part of the storytelling.

After a dramatic image, allow space before the next statement.

Do not:

```text
image
paragraph
image
paragraph
image
paragraph
```

with no breathing room.

Instead:

```text
IMAGE

          silence

STATEMENT

          silence

NEXT IMAGE
```

This makes the experience feel intentional.

# Final Creative Direction

Do not ask the visitor to read about SkyGuide AI.

**Let them feel why it needed to exist.**

The page should move between two worlds:

```text
THE HUMAN WORLD
curiosity
wonder
solitude
discovery
community

          ↕

THE SYSTEM WORLD
Astropy
ephemeris
recommendation
Socket.IO
20Hz telemetry
alignment
microservices
MongoDB
```

The magic is in showing that these are actually the **same story**.

A person looks up.

The system looks back.

And somewhere between the two, SkyGuide answers:

> **“Look there.”**
